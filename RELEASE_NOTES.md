Penumbra Panel v0.2.0

- Fedora support alongside Arch Linux, for matching COSMIC Panel and Settings 1.10.0 or 1.11.0.
- Native RPM detection and exact package guards, including epoch, release and architecture.
- Shared x86_64 binaries built on Fedora 43 with a glibc 2.42 baseline.
- Fedora development dependencies and source-build instructions.
- Release checks cover runtime loading and isolated installation/removal on Fedora 43, 44, 45 and Arch Linux.

Existing panel preferences are preserved. Rasm’s combined Settings release retains its separate Arch Linux requirements.
